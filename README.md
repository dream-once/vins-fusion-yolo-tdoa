# VINS-Fusion YOLO TDOA

Private research workspace combining VINS-Fusion adaptations with the `yolo_vins_msgs` ROS package.

## Layout

- `VINS-Fusion/` — adapted VINS-Fusion source code
- `yolo_vins_msgs/` — YOLO message definitions and ROS node

The VINS-Fusion base project is from https://github.com/HKUST-Aerial-Robotics/VINS-Fusion at commit `be55a937a57436548ddfb1bd324bc1e9a9e828e0`.
